# AI-STUDY-BUDDY
An AI-powered personal learning assistant built for the Naan Mudhalvan project.
Team ID: SWTID-2026-8110

## Problem Statement
Students often lack quick, 24/7 help to clear doubts, understand long notes and practise for exams.

## Objective
Build a simple web app where a student can ask doubts, summarize notes and generate quizzes using AI.

## Features
- Ask Doubt: simple explanations with examples
- Summarize Notes: short bullet-point summaries
- Quiz: multiple-choice questions on any topic
- Explanation level: School / College / Beginner

## Tech Stack
Python, Streamlit, Google Gemini API, GitHub

## How to Run
1. Install requirements: `py -m pip install -r requirements.txt`
2. Run: `py -m streamlit run app.py`
3. Enter your Gemini API key in the sidebar

## Project Phases
1. Problem Understanding: identified student learning problems
2. Idea and Features: doubt solver, summarizer, quiz generator
3. Planning: chose Python, Streamlit and Gemini API
4. Design: simple tabbed layout with a sidebar
5. Development: built app.py with three tabs
6. Testing: tested doubts, summaries and quizzes
7. Deployment: runs locally with Streamlit
8. Final Report and Demo: demo video submitted
